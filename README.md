# StatSearch
Get sports stats fast

# HOW TO BUILD

### Dependencies
- [CMake](https://cmake.org/download/)
- [GCC]()

---

1. Obtain a copy of the repo
2. Create a new directory called "build"
3. CD into it
4. run cmake -G "MinGW Makefiles" .. OR cmake -G "Visual Studio 17 2022" ..
5. run "make" OR open project in visual studio (set Start up project to "StatSearch" and build
